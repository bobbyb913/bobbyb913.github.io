# Stroop Says

> **"Stroop Says" is an handheld game that combines the Stroop effect with the toy "Simon". The objective is to press the button that corresponds with the color the word is written in, rather than the word itself.**

<img src="/assets/images/stroop.png" alt="The Stroop says game, four buttons in primary colors and green around a central screen in a square enclosure"  style="width:900px;margin: auto;display: block">

{% include video id="1qPdraNJLOK96BLD1IY2-5uXz0fRgmmII" provider="google-drive" %}

This project was an exercise in CAD modeling and game design that I took up over the summer between semesters of my grad program. 

"Stroop Says" has two modes: memory mode and speed mode. In memory mode, players observe a pattern and copy it, increasing the length on each successful round. In this mode, the memory of the pattern quickly overcomes the difficulty of the mismatched stimuli from the Stroop effect. 

In speed mode, players press the button corresponding to the color of the word before time runs out. In this mode, the effect is in full force. The colors and words alternate between periods of matching and non-matching. The rhythm illustrates how hard it is to separate the stimuli when they are no longer matching, and making it more fun to try to not get tripped up!
